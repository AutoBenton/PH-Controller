Dosing Parameters

Higher → large doses even for small errors (fast but risks overshoot).
Lower → dose ramps up slowly, gentle correction.
0 → always doses the full max volume regardless of error.
Minimum time between doses. pH keeps being measured and logged at the rate above — only dispensing waits, so the solution has time to mix before the next correction.
If pH is inside the deadband no dose is used, and the next drift is corrected immediately.

Demo Mode simulation

Replaces the real pH sensor with a sine wave that drifts ±0.3 pH around the target, completing one cycle every 40 s (± peak every ~20 s).
Useful for demonstrating pump alternation without live hardware.
